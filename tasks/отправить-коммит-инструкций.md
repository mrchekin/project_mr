# Отправить коммит инструкций

## Запрос пользователя

Отправить подготовленный коммит в origin/main и проверить публикацию.

## Готово, когда

- Обычный git push origin main завершился с кодом 0.
- Через git ls-remote проверено, что опубликованный коммит присутствует в main.
- Результат записан в diary.md и итогах задач; PDF остаются отложенными.

## Не входит

Force push, изменение удалённой истории и продолжение научной сверки.

- подзадачаОт: [[опубликовать-согласованные-инструкции]]

## Итог

git push origin main → 0. git ls-remote origin refs/heads/main подтвердил fc6d1f8b41056571f119e39e139876e7f9b9a6c3. Изменения опубликованы обычным push; force push не использовался. Работа с PDF отложена по просьбе пользователя. Технически готово, ожидает проверки.
