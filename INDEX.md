# INDEX.md — что где лежит

Прочитай первым. По одной строке на важный файл или папку.

- `AGENTS.md` — договор с агентом: цель, проверка, режим, запреты, бюджет.
- `STATUS.md` — текущее состояние проекта (перезаписывается).
- `diary.md` — журнал проекта (только дописывание).
- `ontology.yaml` — онтология проекта (9 классов, 6 правил).
- `ontology/` — заметки классов по одной на каждый класс.
- `notes/` — заметки объектов: индикаторы, группы, источники.
- `tasks/` — задачи и подзадачи со статусами и «Итог».
- `reports/` — отчёты по проекту.
- `memory/L1.md`, `memory/L2.md`, `memory/L3.md` — сжатие статьи Lal 2016.
- `paper/paper.pdf`, `paper/paper.txt` — статья Lal 2016.
- `paper/review_soil_health_indicators.md` — обзор индикаторов здоровья почвы.
- `paper/indicators_table.md` — таблица индикаторов (25 строк).
- `paper/review_soil_health_indicators.tex` — LaTeX-версия обзора.
- `checks/check.py` — техническая проверка; код 0 — технически готово к содержательной проверке, приёмку ставит человек.
- `checks/verify_claims.py` — бланк выборки для содержательной сверки; цитаты и итог заполняют проверяющие.
- `checks/test_properties.py` — шесть действующих тестов таблицы и количества источников в Markdown/LaTeX.
- `checks/check_graph.py` — ограниченная проверка заметок индикаторов и наличия провенанса.
- `METHOD.md` — требования, фактические проверки, ограничения и известные отклонения.
- `scripts/run_verifier.py` — последовательность технических проверок; full проверяет граф, журнал результатов перезаписывается.
- `src/make_graphical_abstract.py` — графический абстракт.
- `cascade.sh` — каскадное сжатие статьи (paper/parts → memory/L1/L2/L3).
- `data/` — исходные данные (только чтение).
- `results/` — производные файлы.
- `library/` — библиотека из OpenAlex (48 работ, метаданные + аннотации).
- `scripts/fetch_library.py` — сборка `library/` из OpenAlex.
- `scripts/search_lab.py` — сравнение BM25 и векторного поиска.
- `reports/my_search_report.md` — отчёт: 6 запросов, выдачи BM25 и вектора.
- `notes/Запрос *.md` — заметки запросов к внешним графам (OpenAlex, Wikidata, локальная библиотека).
- `notes/Источник-*.md` — заметки-источники с провенансом.
