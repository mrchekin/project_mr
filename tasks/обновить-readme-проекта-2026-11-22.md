# Обновить README проекта

## Запрос пользователя

«обнови ридми проекта».

## Готово, когда

README отражает научную задачу, результаты, проверку, сборку и границы инструментов; ссылки проверены; журнал дополнен.

## Не входит

Изменение научных текстов, checks/, таблицы индикаторов, PDF, других документов; сеть, установка пакетов, commit и push. Допускаются README.md, эти заметки tasks/ и добавление записи в diary.md.

- тип: [[Задача]]

## Итог

README обновлён: научная задача, результаты, подтверждение человеком, структура, локальная проверка и сборка, ограничения и история курса.
