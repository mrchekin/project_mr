# Убрать спорные оценки и статусы из README

## Запрос пользователя

Убрать из README спорные утверждения и рассуждения о том, что проверено или не проверено.

## Готово, когда

README описывает назначение, материалы и команды без заявлений о подтверждении, непроверенности и внутренних замечаний; ссылки и техническая проверка проходят.

## Не входит

Изменение научных текстов, договоров, прежних отчётов, оценок индикаторов, PDF и checks/; новая научная сверка, commit и push. Объём: README.md, эти задачи и добавление записи в diary.md.

- тип: [[Задача]]

## Итог

README сокращён до нейтрального описания проекта, материалов, структуры и команд.
