## Запрос пользователя

Две последние лекции с занятий (инфраструктура агентов; проверка и
развёртывание). Нужно развернуть своего агента — репозиторий
`project_mr` — по теме VPS. По уточнению: VPS пока нет, каталог и ключи
не выбраны. Решение: развернуть локально на DeepSeek Harness (DSH) и
подготовить пакет для будущего VPS; каталог — `~/agent_deploy/`.

## Готово, когда

- В `~/agent_deploy/` лежит пакет развёртывания: `bootstrap.sh`, `run.sh`,
  `verify.sh`, `config/` (скиллы, `AGENTS.deploy.md`), `vps/`
  (`install-vps.sh`, `agent.service`, `ssh-config.example`), `README.md`.
- Локальное развёртывание выполнено: клон репозитория, venv, зависимости,
  скиллы в `.dsh/skills`.
- `verify.sh`: `checks/check.py` = 0, `pytest checks`, `check_graph.py`;
  smoke-ответ агента DSH; лог `verification.log`.
- VPS-часть готова: `install-vps.sh`, systemd-юнит, пример SSH через
  jump-хост, раздел README «как перенести».

## Не входит

- Аренда и настройка реального VPS (сервера нет).
- Изменение `checks/`, научных данных и приёмка результатов.
- Копирование секретов модели в пакет.

## Итог

- Развёрнуто локально в `~/agent_deploy/` на DSH: клон `main`, 88 PDF, venv
  (Python 3.14.4), зависимости, скиллы в `.dsh/skills`.
- `~/agent_deploy/verify.sh` → exit 0: `checks/check.py`=0, `pytest checks`=24 passed,
  `check_graph.py`=0, smoke `dsh --profile headless` прочитал `AGENTS.md` и
  перечислил три запрета (`~/agent_deploy/verification.log`).
- VPS-пакет готов: `vps/install-vps.sh`, `agent.service`, `ssh-config.example`,
  раздел README «Перенос на VPS». Реального сервера нет — на VPS не проверялось.
- Итог: технически выполнено, ожидает проверки человеком.
