# Сборка PDF и отчёт

- тип: [[Задача]]
- подзадачаОт: [[раскрыть-сокращения-английской-версии]]

## Запрос пользователя

Собрать PDF дважды, проверить страницы, ссылки, переполнения, Author.

## Готово, когда

Код 0 дважды, ≤ 6 страниц, нет undefined refs и overfull, отчёт заполнен.

## Не входит

Содержательная сверка с PDF-первоисточниками.

## Итог

pdflatex ×2, код 0/0; 6 страниц; 0 undefined refs; 0 overfull; Author пуст,
"Anonymous authors" на первой странице. Отчёт дополнен разделом о сокращениях.
