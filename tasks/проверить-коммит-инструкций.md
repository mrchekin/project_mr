# Проверить состав коммита инструкций

## Запрос пользователя

Проверить состав накопленных изменений, выполнить технические проверки и подготовить коммит.

## Готово, когда

- Состав изменений ограничен согласованными документами, задачами, журналом и записью состояния публикации.
- check.py, pytest, check_graph.py и git diff --check → 0.
- Подготовлен обычный коммит в текущей main; изменения пользователя сохранены.

## Не входит

Изменение PDF, научного обзора, таблицы, checks/ и кода.
