# Опубликовать согласованные инструкции

## Запрос пользователя

Пользователь остановил работу с PDF и поручил закоммитить и запушить существующие изменения на GitHub.

## Готово, когда

- В origin/main присутствует коммит с четырьмя согласованными документами, журналом и четырьмя заметками завершённого первого этапа.
- Проверки check.py, pytest, check_graph.py и git diff --check завершаются с кодом 0.
- Созданы эта задача и две подзадачи, результаты публикации дописаны в diary.md.
- PDF, paper/, checks/ и код не изменены; нет незакоммиченных изменений после публикации учётных записей.

## Не входит

Продолжение сверки PDF, правка научных оценок, изменение проверок, принудительный push и публикация непроверенных научных материалов.
