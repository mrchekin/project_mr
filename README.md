# Чувствительные показатели здоровья почвы

Учебный проект курса ШАД Яндекса об ИИ-агентах для исследователя.
Научная задача — подготовить обзор показателей здоровья почвы: сравнить
их отклик на агротехнические практики, методы измерения и условия применения.

Агент помогает читать литературу, вести заметки, таблицу индикаторов,
граф проекта и версии статьи. Научные утверждения проверяет автор
по оригинальным публикациям. Правила работы закреплены в [AGENTS.md](AGENTS.md).

## Локальная проверка

Для проверки нужна рабочая копия выбранной версии проекта и локальные
научные материалы. В последнем зафиксированном прогоне использован
Python 3.14.4; зависимости проверки закреплены в
[requirements.txt](requirements.txt).

Подготовка окружения в Ubuntu/WSL из корня проекта:

~~~bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
~~~

В Windows PowerShell окружение активируется командой:

~~~powershell
.\.venv\Scripts\Activate.ps1
~~~

Технические проверки:

~~~bash
python -B checks/check.py
python -B -m pytest checks -q -p no:cacheprovider
python -B checks/check_graph.py
~~~

Последний зафиксированный результат от 22.11.2026:
**check.py — код 0; pytest — 24 passed; check_graph.py — код 0.**
Семь тестов проверяют файловые свойства, 11 — свойства функций и контрольные
ошибки, шесть — связи между артефактами.
Условия запуска и дополнительные проверки описаны в
[отчёте](reports/project_update_2026-11-22.md).

[Общий запуск](scripts/run_verifier.py) выполняет эти проверки по этапам
через тот же интерпретатор и **перезаписывает** `results/verifier_log.csv`.
Для сохранения старого журнала используйте отдельные команды выше.
Параметр no:cacheprovider отключает кэш pytest, но не базу примеров Hypothesis.

### Научные материалы после клонирования

Исходные PDF, конвертированные тексты и бинарные рисунки не входят в Git.
Для проверки существования источников нужны файлы с точными именами
из столбца source_file таблицы индикаторов. Без них соответствующие проверки
завершатся ошибкой.

Ссылка на материалы, ранее указанная автором:
[архив на Яндекс Диске](https://disk.360.yandex.ru/d/iLRsL0SoqkfneQ).
Её доступность при обновлении README не проверялась.

requirements.txt описывает зависимости проверки. Конвертация научных PDF,
поиск и сборка LaTeX требуют своих инструментов; их наличие из этого файла
не следует. Сетевой поиск, скачивание и установка дополнительных инструментов
агентом требуют отдельного поручения.

## Сборка статьи

Для английской конференционной версии нужен pdflatex и установленные
LaTeX-пакеты, используемые классом [ai4science_ysda.cls](paper/ai4science_ysda.cls).
Из корня проекта:

~~~bash
cd paper
pdflatex -interaction=nonstopmode -halt-on-error conference_review_en.tex
pdflatex -interaction=nonstopmode -halt-on-error conference_review_en.tex
cd ..
~~~

Два прохода обновляют ссылки и нумерацию. Итог — локальный
`paper/conference_review_en.pdf`. После сборки проверяются журнал,
таблицы, ссылки и внешний вид страниц.

Русская версия собирается аналогично из `conference_review.tex`.
Для полного обзора используется `review_soil_health_indicators.tex`;
ему дополнительно нужен локальный рисунок
`paper/figures/graphical_abstract.pdf`.

## Границы проверки и следующие задачи

Технический успех относится к полному обзору и таблице. Он не является
автоматической проверкой содержания конференционных версий.
Полная карта условий — в [METHOD.md](METHOD.md).

- `check_graph.py` требует минимум пять заметок индикаторов и наличие
  провенанса у источников; он не проверяет все типы отношений онтологии.
- Тест сортировки проверяет функцию на сгенерированных данных,
  а не порядок строк рабочего файла.
- `verify_claims.py` ожидает ссылку с номером страницы. В текущем полном
  обзоре он извлекает 0 утверждений и не обеспечивает выборку для сверки.
  Старые spot_check-отчёты относятся к указанным в них версиям.
- Остаются отдельные вопросы: [синхронизация раздела 2.1](tasks/сверить-раздел-2-1-md-tex.md)
  полного Markdown/LaTeX, порядок строк и medium-high в таблице,
  две почти пустые конвертации и обозначение Mu/Mn в памяти Lal.
- Пересборка полного PDF успешна, но его журнал содержит 86 предупреждений
  Overfull; улучшение этой вёрстки остаётся отдельной задачей.

Подтверждение человеком итоговой английской статьи сохранено.
Изменённые научные утверждения и числа требуют сверки новой версии.
