## Запрос пользователя

Проверить согласованные изменения, оформить итоги задач и дописать журнал.

## Готово, когда

- Выполнены python checks/check.py, pytest без кэша, check_graph.py и git diff --check; записаны их коды.
- В задачах ровно по одному status:, есть обязательные разделы и связи; по завершении status: выполнена.
