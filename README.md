# Агент для обзора индикаторов здоровья почвы

Учебный проект курса ШАД «ИИ-ассистенты для исследователя». Агент помогает вести обзор индикаторов здоровья почвы: работает с литературой, заметками, графом проекта и таблицей индикаторов. Результаты его работы проверяются скриптами и человеком.

В репозитории собраны материалы трёх этапов:

- **ДЗ 1 «Среда и контекст»** — настройка работы агента, управление контекстом, онтология, граф и поиск литературы (практики 1–5).
- **ДЗ 2 «Проверка»** — методика, верификатор, дерево подцелей и тесты на свойствах (практики 6–7).
- **Развёртывание агента** — локальный запуск на DeepSeek Harness и пакет для переноса на VPS (10.11.2026).

## Как воспроизвести проверку ДЗ 2

Клонировать репозиторий, перейти в ветку `hw2` и установить зависимости в виртуальное окружение:

```bash
git clone https://github.com/mrchekin/project_mr.git
cd project_mr
git switch hw2
python -m venv .venv
```

Активировать окружение:

```bash
# Linux / macOS
source .venv/bin/activate

# Windows PowerShell
.\.venv\Scripts\Activate.ps1
```

Затем установить зависимости и запустить проверку:

```bash
python -m pip install -r requirements.txt
python scripts/run_verifier.py
```

В Windows при необходимости вместо `python` можно использовать `py -3` при создании виртуального окружения. На текущем `main` те же проверки проходят (24 passed; ветка `hw2` зафиксирована 06.11.2026).

**Исходные PDF:** файлы PDF и текстовые копии статей исключены из Git через `.gitignore`. Поэтому после клонирования их необходимо отдельно разместить в `paper/` под именами, указанными в столбце `source_file` таблицы; иначе проверка существования источников завершится ошибкой. Итоговый PDF обзора также не входит в репозиторий. Это сделано для экономии места репозитория.
**Получить PDF и текстовые копии статей можно по ссылке:** https://disk.360.yandex.ru/d/iLRsL0SoqkfneQ
`run_verifier.py` последовательно запускает проверки и **перезаписывает** `results/verifier_log.csv`. Если нужно сохранить предыдущий журнал, сначала сделайте его копию. Отдельные проверки можно запустить так:

```bash
python checks/check.py
python -m pytest checks -q
python checks/check_graph.py
```

## Границы автоматической проверки

Успешный запуск проверяет только реализованные условия: например, структуру таблицы, часть допустимых значений и отдельные свойства графа. Он не подтверждает научную достоверность обзора, соответствие оценок чувствительности первоисточникам или правильность указанных страниц. Тесты также не подтверждают полное покрытие таблицы заметками и одинаковый состав литературы в Markdown и LaTeX только потому, что число позиций совпадает.

Для содержательной проверки требуется сверить утверждения с исходными публикациями. Скрипт `checks/verify_claims.py` создаёт бланк, но не выполняет сверку и может перезаписать отчёт за тот же день; он распознаёт только ссылки вида «(… с. N)». В текущей версии обзора ссылки оформлены как «(Автор, Год)», поэтому скрипт находит 0 утверждений — содержательная проверка выполняется вручную по сохранённым отчётам `reports/spot_check_2026-11-09*.md` и `.md`-копиям источников. Решение о приёмке результата остаётся за автором проекта.
