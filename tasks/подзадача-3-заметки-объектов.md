# Подзадача 3: заметки объектов в notes/

## Запрос пользователя

Записать новые объекты (индикаторы, группы, источники) в `notes/`
со связями по `ontology.yaml`.

## Готово, когда

- Для каждого нового индикатора есть заметка `notes/<название>.md`
  со строкой `- тип: [[Индикатор]]` и связями принадлежитГруппе /
  подтверждёнИсточником.

## Не входит

- Выдумывание классов, которых нет в `ontology.yaml`.

- тип: [[Задача]]
- подзадачаОт: [[дополнить-таблицу-индикаторов]]
