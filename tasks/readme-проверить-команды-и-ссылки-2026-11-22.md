# Проверить команды и ссылки README

## Запрос пользователя

«обнови ридми проекта».

## Готово, когда

Локальные Markdown-ссылки README существуют и доступны в Git; команды согласованы с файлами проекта; check.py и diff --check проходят.

## Не входит

Изменение научных текстов, checks/, таблицы индикаторов, PDF, других документов; сеть, установка пакетов, commit и push. Допускаются README.md, эти заметки tasks/ и добавление записи в diary.md.
