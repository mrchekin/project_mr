## 2. Договор и фактические проверки

| Требование | Реализация | Ограничение |
|---|---|---|
| Заголовки полного MD-обзора | check.py: минимум семь заголовков второго уровня и группы подстрок | Содержание не проверяется |
| Семь столбцов | test_properties.py и check_graph.py сравнивают заголовок; check.py требует обязательные столбцы | check.py отдельно не требует точного порядка |
| Размер таблицы | check.py: минимум 10 строк; test_indicators_table_size: ровно 25 | Полнота научного набора не установлена |
| Категории | Файловый тест требует chemical, physical, biological, labile carbon | check.py также допускает microbial |
| Чувствительность | check.py и test_sensitivity_whitelist | Код допускает medium-high; его научная оценка остаётся отдельным вопросом |
| sensitivity_target | check.py и test_sensitivity_target_whitelist | Содержательная правильность воздействия не проверяется |
| Названия | Уникальность, допустимая длина, ограниченный список заглушек | Синонимы и научный смысл не устанавливаются |
| Источники | Существование пути, расширение PDF/MD/TXT | Релевантность и безопасное нахождение внутри paper/ полностью не проверяются |
| source_page PDF | Целое 1..999 | Реальная страница и цитата не сверяются |
| source_page MD/TXT | Отсутствие заглушек | Фрагмент по указателю не разыскивается |
| Порядок рабочей таблицы | Автоматической проверки самого файла нет | test_sensitivity_order_is_monotone проверяет функцию на сгенерированных данных |
| Сводная таблица обзора | test_review_has_summary_table: минимум 10 строк данных | Смысл и согласованность оценок не проверяются |
| Упоминания индикаторов | Не менее пяти совпадений нормализованных имён | Совпадение подстроки не равно содержательному описанию |
| Литература MD/TEX | test_md_and_tex_literature_match сравнивает количество | Состав источников и текст не сравниваются |
| Граф | Минимум пять заметок индикаторов и наличие найденЗапросом | Полное покрытие 25 строк и типы отношений не проверяются |
| Карточки с PDF | Интеграционный тест ищет упоминание обзора | Не проверяет направление, тип связи и научную атрибуцию |
| Давность сборки | test_pdf_is_newer_than_tex сравнивает время изменения | При отсутствии PDF — skip; сборка и содержание этим не доказаны |

## 4. Окружение и запуск

В сеансе 22.11.2026 используется Python 3.14.4 из .venv.
requirements.txt существует и фиксирует семь пакетов, в том числе pytest 9.1.1,
hypothesis 6.170.12 и PyYAML 6.0.3. Это зависимости проверки, а не полный
состав среды конвертации PDF, поиска и LaTeX.

scripts/run_verifier.py использует sys.executable:

| Шаг | Команда текущего интерпретатора | Область |
|---|---|---|
| dry | checks/check.py | Полный обзор и таблица |
| smoke | -m pytest checks/test_properties.py -q | Семь файловых тестов |
| sweep | -m pytest checks -q | Все 24 теста |
| full | checks/check_graph.py | Ограниченная проверка графа |

Скрипт перезаписывает results/verifier_log.csv. Для сохранения исторического
журнала проверки запускаются отдельно:

    .venv/bin/python -B checks/check.py
    .venv/bin/python -B -m pytest checks -q -p no:cacheprovider
    .venv/bin/python -B checks/check_graph.py

no:cacheprovider отключает кэш pytest, но не базу примеров Hypothesis.
Для режима без записи дополнительно нужен профиль Hypothesis с database=None.

LaTeX собирается отдельно дважды из paper/. Новый журнал и итоговый PDF
проверяются на ошибки, ссылки, переполнения и читаемость. Тесты полного
обзора автоматически не проверяют конференционные версии.

## 5. Содержательная проверка

verify_claims.py распознаёт только ссылки своего шаблона с номером страницы.
На текущем полном обзоре extract_claims() возвращает 0. Не запускать main()
как доказательство содержательной проверки и не менять научный формат
ссылок ради извлечения. Старые spot_check-отчёты не перезаписывать.

Для отдельной выборки фиксировать версию, дату, seed, тезис, оригинальный файл,
физическую страницу, цитату, проверяющего и итог. Договорный порог: не менее
четырёх подтверждений из пяти и решение человека. Ошибки исправляются
независимо от порога. Исторический отчёт относится только к указанной версии.

Ручная сверка английской статьи с оригинальными научными публикациями
подтверждена пользователем 22.11.2026. Она записана как проверка человеком,
а не результат автоматических тестов или повторного чтения агентом.

## 6. Граф, задачи и история

Типизированные отношения соответствуют domain/range ontology.yaml.
Если подходящего отношения нет, использовать обычную ссылку с пояснением,
а не менять смысл существующего отношения. Валидность типов связей
не подтверждает научное содержание карточек.

Агент ставит выполнена; принята — только по решению человека. Исторические
решения не переопределяются. diary.md дополняется, STATUS.md описывает текущее.

Отчёты ДЗ, эксперименты с намеренными ошибками и results/verifier_log.csv
сохраняются как история конкретных версий, с прежними числами тестов и источников.
