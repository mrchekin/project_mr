# Подготовить отчёт по индикаторам для коллег

## Запрос пользователя

Подготовить `reports/indicators_summary.md` — краткий отчёт по таблице
индикаторов для коллег: топ-5 самых чувствительных индикаторов, у каждого
ссылка на PDF-источник.

## Готово, когда

- `reports/indicators_summary.md` существует;
- в нём ≥5 индикаторов, у каждого — ссылка на PDF из `paper/`;
- все эти индикаторы есть в `paper/indicators_table.md`.

## Не входит

- Изменение `checks/`.
- Скачивание новых PDF.
- Сетевые запросы.
- Статус «принята» (ставит только человек).

- тип: [[Задача]]

## Итог

Создан `reports/indicators_summary.md` — топ-5 самых чувствительных
индикаторов (все sensitivity=high): SOC content, POXC, microbial biomass C,
total PLFA, aggregate stability. У каждого — ссылка на PDF из `paper/`
и страница. Все 5 индикаторов есть в `paper/indicators_table.md`.
`python3 checks/check.py` → код 0. Статус «принята» не ставился — ставит человек.
