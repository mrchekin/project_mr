# Раскрыть сокращения в английской конференционной статье

- тип: [[Задача]]

## Запрос пользователя

Раскрыть сокращения при первом употреблении в `paper/conference_review_en.tex`,
не менять научное содержание, пересобрать PDF, отчитаться.

## Готово, когда

- в `paper/conference_review_en.tex` каждое сокращение из списка раскрыто при
  первом употреблении в основном тексте;
- аннотация без неиспользуемых сокращений;
- PDF собран дважды, ≤ 6 страниц, без undefined refs и overfull;
- отчёт `reports/conference_review_en_notes.md` содержит места определений.

## Не входит

Русская версия, полный обзор, таблица индикаторов, `checks/`, `AGENTS.md`,
класс LaTeX, сеть, установка пакетов, commit/push, подача.
