# Сборка и проверка конференционной версии

- тип: [[Задача]]
- подзадачаОт: [[редактура-конференционной-версии]]

## Запрос пользователя

Собрать PDF дважды, проверить число страниц, поле автора, неопределённые ссылки
и переполнения. Выполнить `checks/check.py` и отметить границы его применимости.

## Готово, когда

`pdflatex` дважды → код 0, не более 6 страниц, 0 неопределённых ссылок,
0 переполнений; `checks/check.py` → код 0.

## Не входит

Установка отсутствующих пакетов; содержательная сверка по PDF.

## Итог

Выполнено: 6 страниц, 0 неопределённых ссылок, 0 `Overfull \hbox`.
`checks/check.py` → код 0, относится к полному обзору.
